# Changelog

## 1.0.0 - 2026-11-02

First public release.

- Find a person and see their info from a Telegram user ID, in six ways: direct chat, profile, username link, Telegram Web, account info and profile photo.
- Input starts from the numeric ID (Arabic and Persian digits included); `@username`, `t.me` link, `tg://user?id=` link, forwarded message, shared contact, and `?start=ID` deep links are converted to the ID first.
- One free trial per user, then 1 Telegram Star per use or a 30-day subscription.
- A use that returns no result is not counted. The "link did not work" button restores the free trial or refunds the Star (up to 3 reports per user).
- Favorites with aliases, recent IDs, spam protection and a ban list.
- Developer panel: statistics, subscriptions, operation log, payments, broadcast with progress bar, ban and unban, and `/refund`.
- Arabic and English interface, chosen automatically from the user's Telegram language.
